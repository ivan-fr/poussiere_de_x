## Geometry note

Each tracked path uses exact Pandrosion slopes generated from the polynomial system profile, preserving `Q(a,z)(z-a)=F(z)-F(a)` up to roundoff. The homothety changes the coordinate geometry used by the paths; micro-order only changes which start paths are retried.
